#  Kütüphane Otomasyonu

## İçindekiler
- `index.html`: Uygulamanın tamamı. Ayrı kurulum veya sunucu gerekmez.

## Çalıştırma
1.`index.html` dosyasını bir tarayıcıda açın.
2. Kitap ekleyebilir, arayabilir, düzenleyebilir, silebilir; ödünç verme ve iade işlemlerini yapabilirsiniz.


## Önemli
Bu başlangıç sürümü verileri aynı cihaz ve tarayıcıdaki `localStorage` alanında saklar. Çok kullanıcılı sistem veya internet üzerinden ortak veri için sunucu/veritabanı gerekir.
