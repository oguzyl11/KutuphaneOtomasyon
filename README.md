# Basit Kütüphane Otomasyonu

## İçindekiler
- `index.html`: Uygulamanın tamamı. Ayrı kurulum veya sunucu gerekmez.

## Çalıştırma
1. ZIP dosyasını çıkarın.
2. `index.html` dosyasını bir tarayıcıda açın.
3. Kitap ekleyebilir, arayabilir, düzenleyebilir, silebilir; ödünç verme ve iade işlemlerini yapabilirsiniz.

## Telefonda / GitHub'a yükleme
- GitHub deposunda **Add file → Upload files** seçeneğiyle ZIP'i veya çıkarılmış `index.html` dosyasını yükleyebilirsiniz.
- GitHub Pages kullanacaksanız `index.html` dosyasını deponun ana dizinine yükleyin.
- Replit'te basit bir HTML/CSS/JS projesi oluşturup `index.html` içeriğini kullanabilirsiniz.

## Önemli
Bu başlangıç sürümü verileri aynı cihaz ve tarayıcıdaki `localStorage` alanında saklar. Çok kullanıcılı sistem veya internet üzerinden ortak veri için sunucu/veritabanı gerekir.
